# Web Programming Final Project - 67051099
## MiniShop Dashboard & E-Commerce Web Application

โปรเจกต์ตั้งอยู่ในโฟลเดอร์ `minishop-dashboard/`

### คำสั่งเปิดใช้งาน:
```bash
cd minishop-dashboard
npm run dev
```
แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:5173`

อ่านรายละเอียดการทำงานและโครงสร้าง Component ทั้งหมดได้ที่ [minishop-dashboard/README.md](./minishop-dashboard/README.md)
